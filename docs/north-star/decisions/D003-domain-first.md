# D003 Put the domain first and keep one verb per action

Decided 2026-10-05. Use `ncly <domain> [<resource>] <verb>`, singular nouns, and one verb per action, as [Usage](../contract/usage.md) defines.

**Revision, 2026-10-24.** [D064](D064-shared-domains.md) applies this rule to named extensions within a shared domain.

**Why.** Domain help limits what an agent must read. Consistent verbs, drawn from `gh`, make other domains predictable.

**Rejected.** Verb-first commands and imported scripts that keep a different grammar.
