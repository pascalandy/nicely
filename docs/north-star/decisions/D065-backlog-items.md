# D065 Plan work by extension and core backlog items

Decided 2026-10-25 by Pascal.
`XT-nnn` identifies extensions and `COR-nnn` identifies core, with only 1xx for chosen work and 6xx for ideas.
Each item that ships from Nicely takes the next minor version, starting with v0.24.0.
Patch versions cover intervening fixes.
An extension maintained in its own repository, such as XT-101, keeps its own versions.
[The backlog README](../../backlog/README.md) owns the format, statuses, queue, cards, renumbering, and frozen history.

**Revises.** [D042](D042-milestones-and-cards.md) keeps small cards and moves planning from milestones to backlog items.
[D043](D043-milestone-versions.md) replaces milestone versions with the next minor per shipped item.

**Why.** Ownership stays visible as an extension evolves across releases.
The queue expresses delivery order without renumbering unrelated capabilities.
Ideas retain their conditions without becoming promised work.

**Rejected.** New milestones, a separate parking lot, and versions derived from item numbers.
