# D002 Name the project Nicely and the command ncly

Decided 2026-10-05. The project is Nicely, its command is `ncly`, and its repository is `pascalandy/nicely`. The Go module is `github.com/pascalandy/nicely`.

**Why.** At the decision date, `nicely` was taken on PyPI and npm, but neither package installed that command. Nicely was free in Homebrew and the AUR. The shorter `ncly` was free on PyPI, npm, crates.io, and Homebrew.
