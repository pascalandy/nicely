# D025 Split the docs by question, and work in milestones

Decided 2026-10-05, revised 2026-10-09. Give each question and decision its own file under [the documentation rules](../dev-preferences.md#keep-the-docs-a-tower). [AGENTS.md](../../../AGENTS.md#find-what-you-need) maps owners and [milestone preparation](../../milestones/README.md#make-a-milestone-ready) links cards to ready specs.

**Why.** One owner prevents repeated rules. Small files let agents read only what they need. An extension's spec stays with its code.

**Rejected.** Specs inside milestones, one combined guide, or one file for all decisions. Each repeats rules or loads unrelated context.
